# 2026-10-21

## 通读 Image-Studio 开源项目并产出 AGENTS.md

- 完整梳理项目：Wails(Go+React/TS) 桌面端 + `go-cli` 共享请求内核 + `shared/kernel` 跨端请求规范 + Android WebView 壳层 + Cloudflare Worker + Gio 客户端。
- 关键结论：
  - 桌面端真实请求实现只在 `go-cli/pkg/client`（image-studio 通过 replace 复用）；前端远程内核在 `platform/runtime/remote-kernel`，两侧语义必须同步。
  - 生成事件契约：`log/progress/preview/result/error:<jobId>`，前端用 `requestedJobId` 先绑监听再提交。
  - `shared/kernel/requestModel.js` 是字段规范单一真相源；Responses 固定带 VERBATIM instructions。
  - 输出目录分 `images/ thumbs/ previews/ log/`；文件名必须带 jobID 前 6 位防并发覆盖。
  - 硬约束：分层不可穿透、历史不裁剪、失败必须可见、拖拽统一 `useNativeFileDrag`、不跨 bridge 传大 base64。
- 产出：仓库根目录 `AGENTS.md`。
- 用户偏好：AGENTS.md 只保留 AI 自己需要的开发规则，尽量短，避免 token 浪费；后续开发全部由 AI 完成。最终 32 行 / ~1.4k 字符：内核入口 2 行 + 14 条规则单行 + 改动路径 3 行 + 验证 1 行。已删除项目介绍、分层教学、存储细节、文档索引、表格格式、二次开发礼仪。
- 本机环境现状：Node 22（仓库要求 24），Go 与 Wails CLI 未安装，目录无 `.git`。
